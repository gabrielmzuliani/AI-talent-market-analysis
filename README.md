# The AI talent market: A Statistical Analysis of Salary Gaps and Work Mode Trends 
This project investigates the AI job market by analyzing how salary correlates with company size and work modes, and evaluating whether company sizes and work modes are statistically related to each other. Using a dataset of 71,913 AI job records from 2020 to 2026, the analysis applies statistical hypothesis testing to uncover pay gaps and structural trends across flexible and non-flexible work cultures.
